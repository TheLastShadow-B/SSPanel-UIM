# 前端 UI 重设计 — 设计文档

日期:2026-07-13
范围:用户端 + 登录注册(约 31 页);管理端保持 tabler 现状
参考:US Mobile 用户面板(app.usmobile.com,实测抓取)

## 背景与目标

现有前端为单主题 `tabler`(101 个 Smarty 模板):Tabler CSS + 图标、htmx、DataTables 全部经 jsDelivr 拉取 `@latest`,无构建系统,样式/JS 内联在各 `.tpl` 中。整体是"能用的默认后台模板",无品牌感,样式难维护。

目标:
1. 以 US Mobile 的设计语言重写用户端,建立自有设计系统(设计 token 统一管理,不再内联样式)。
2. 信息架构升级为"订阅 = 一等实体",为**一个用户购买多个订阅**的后续规划预留 UI 结构。
3. 渐进迁移、可随时回滚,后端控制器改动最小化。

## 参考设计语言(US Mobile 实测)

- 主色:饱和蓝 `#1D5FF6`;按钮为胶囊形(radius 32px);次要操作用浅色 ghost 按钮
- 画布:极浅蓝灰 `#F9FAFD`;卡片纯白、radius 16px、1px 发丝边框 `#E1E3E6`、无阴影
- 字体:GT Walsheim(商业字体)→ 开源替代 Outfit(拉丁)+ 系统中文栈(PingFang SC / MiSans / HarmonyOS Sans SC);正文灰 `#52525B`
- 布局:左侧白色侧边栏(图标+文字,三分组),顶部全局搜索(⌘K)+ 通知铃铛
- 核心组件:环形流量进度圈、胶囊分段 tab(选中实心蓝)、浅灰底统计瓦片(`#F3F5F7`,radius 10px)、带图标徽章 pill、key-value 行 + 右侧 pill 值、虚线边框"新建实体"幽灵卡、实体头(大头像 + 名称 + 状态徽章 + 右侧速览条)
- 列表页 → 详情页钻取模式(My Lines / Pools → 详情三 tab:Overview / Lines / Settings)

## 信息架构(已与用户确认)

侧边栏三分组:
| 分组 | 条目 |
|---|---|
| 快速操作 | 购买订阅、余额充值 |
| 主导航 | 我的订阅、用量统计、公告、工单、邀请返利、使用文档 |
| 账户 | 订单记录、个人设置、登出 |

页面层级:
1. **我的订阅**(登录后首页,`/user`):订阅卡片网格。每卡 = 套餐图标 + 套餐名 + 状态徽章 + 到期 banner + 流量摘要条;旁置"+ 购买新订阅"幽灵卡与签到/邀请营销卡。当前每人一个订阅 = 一张卡;后端将来支持多订阅时此页结构零改动。
2. **订阅详情**(`/user/subscription`):实体头(套餐名 + 到期日 + 状态徽章;右侧速览:剩余流量 + 续费 CTA、等级/倍率)+ 胶囊 tab:
   - 总览:流量环 + 3 统计瓦片(本周期已用/较上周期/总量)+ 用量图(带限额虚线)+ 在线设备卡
   - 节点:可用节点表格卡(名称、类型徽章、倍率、状态),卡内搜索(整合现 `server.tpl`/`rate.tpl`)
   - 设置:订阅链接卡(链接+二维码+一键导入+重置)、下期账单卡(大数字价格 + 自动续费状态)
3. **商店 → 结算**:产品卡(大数字价格/月 + 特性列表)→ 订单摘要 + 优惠券 + 支付方式。
4. 其他页面套用同一模式:工单(表格卡 + 对话流)、订单/账单(Invoice 卡)、邀请(大数字奖励 + 分享卡)、公告、文档、个人设置(两列设置卡)。`profile.tpl`/`edit.tpl` 合并为设置页。

## 技术方案(已与用户确认)

- **并行新主题目录** `resources/views/cafe/`,不动 tabler。`View::getSmarty()` 模板目录设为 `[cafe, tabler]` 数组,未迁移页面(含管理端)自动回退 tabler 渲染,按用户 `theme` 字段灰度、随时回滚。
- **Tailwind CSS v4**:构建时经 `@tailwindcss/cli` 生成 `public/theme/cafe/app.css`,产物提交仓库,生产环境不需要 Node。设计 token 用 v4 的 CSS `@theme` 定义。
- **交互**:保留 htmx(表单提交/局部刷新,现有后端 HX-Redirect 风格不变)+ Alpine.js(下拉、tab、模态、toast)。逐步淘汰 jQuery/DataTables(用户端)。
- **资产自托管**:字体、Alpine、htmx、二维码库均放 `public/theme/cafe/`,摆脱 jsDelivr `@latest` 的不可控性(演示阶段暂允许 CDN,正式版切换)。
- 后端仅允许小改:`View.php` 模板目录数组;`SubscriptionController::index` 补 assign(流量日志、在线设备)供详情页使用。

## 深色模式

沿用现有 `user->is_dark_mode` 开关,token 层换值("夜间咖啡厅"变体):画布 `#0F1115` 系、卡片 `#16181D`、发丝边框透明度化、主色亮度上调。首版先保证浅色完整,深色随 token 骨架一并铺好。

## 错误处理与状态

- 表单错误:沿用 htmx JSON `{ret, msg}` → 顶部 toast(替代现 modal 弹窗)
- 空状态:每个列表页配插画 + 引导 CTA(如无订阅 → 引导商店)
- 加载:htmx 请求期间按钮 spinner + 禁用

## 测试与验证

- Smarty 渲染冒烟:关键页面 GET 200 + 关键元素存在(pest,沿用现有测试栈)
- 视觉验证:测试服务器(见 secret/TestServer.md)真实浏览器截图走查,移动端断点(375px)与桌面(1440px)
- 回滚:将用户 theme 切回 tabler 即恢复旧 UI

## 迁移阶段
